This folder should contain presentation files (PDF or PPTX format).

Files to add:
- proposal.pdf (or proposal.pptx)
- progress1.pdf (or progress1.pptx)
- progress2.pdf (or progress2.pptx)
- final.pdf (or final.pptx)

You can:
1. Export presentations as PDF or PPTX
2. Export from PowerPoint, Google Slides, Keynote, etc.
3. Create sample presentations for testing

The presentations are dynamically loaded in presentations.html.
The file names are referenced in js/main.js in the presentations array.

To add more presentations, edit the presentations array in js/main.js and add corresponding files here.
