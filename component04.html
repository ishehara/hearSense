Component 04

💬 Two-Way Communication System

An HCI-based interactive platform enabling effective daily communication between children with speaking disabilities and their parents using visual sign-based interaction

← Back to Home

What Is This Component?

A visual two-way communication bridge for children and their families

The Sinhala Two-Way Communication System is an HCI-based interactive platform designed to enable effective daily communication between children with speaking disabilities and their parents. This system allows children to express their needs using visual sign-based selections — including sign videos, icons, and categorized options — while parents can respond using sign visuals and text instead of voice communication.

Unlike traditional communication tools, this component supports real-time two-way interaction, ensuring that both the child and parent can communicate naturally without relying on spoken language. Additionally, the system integrates a machine learning-based prediction module within the parent interface to assess the child's communication level and provide insights based on behavioral observations.

What Problem Does It Solve?

Children with speaking disabilities face multiple communication barriers in daily life

❌ The Challenges

  • Limited access to Sinhala Sign Language (SSL) education
  • Parents not being familiar with sign language
  • Communication barriers within families
  • Lack of practical tools for everyday interaction
  • Existing systems focusing only on learning or one-way translation
  • Difficulty expressing daily needs (food, toilet, illness)

✅ The Solutions

  • A two-way communication system for real-life interaction
  • Simple visual-based communication for children
  • Parent-friendly response system using signs and text
  • Reduced dependency on full SSL knowledge
  • Support for daily communication scenarios
  • Integration with AI-based communication level prediction

System Functionality Overview

Two dedicated interfaces — one for the child, one for the parent

Child Interface

👶 Child's View

Designed for ease of use with large icons and simple navigation:

  • Child selects one category at a time
  • Displays sign videos and icons for communication
  • When a selection is made, a voice output is generated for the parent
Example: "මට බත් කන්න ඕන"
Parent Interface

👨‍👩 Parent's View

Displays the child's message clearly and enables easy response:

  • Shows selected message as Sinhala text
  • Shows corresponding sign video or image
  • Parent responds using predefined sign visuals/videos
  • No need for spoken communication from either side

How Does It Work in Real Life?

A complete communication flow from child to parent and back

1

Child Opens App

The child sees colorful categories (Food, Drinks, Toilet, etc.) with large, friendly icons.

2

Child Selects Category

The child taps a category — for example, Food — to see specific options within it.

3

Child Chooses an Option

The child selects their specific need, for example "මට බත් කන්න ඕන" (I want rice).

4

System Output

The system plays a voice output for the parent and displays the corresponding sign visual.

5

Parent Receives Message

The parent sees the Sinhala text and a matching sign video/image on their interface.

6

Parent Responds

The parent selects an appropriate sign-based response. The child understands visually without needing spoken language.

Machine Learning Integration

AI-powered communication level prediction on the parent side

🤔 How It Works

  • Parent answers a questionnaire based on the child's behavior and communication patterns
  • System analyzes responses using a trained ML model
  • Predicts the child's current communication level with a confidence score

🎯 Purpose

  • Helps parents understand their child's development stage
  • Supports early intervention when communication gaps are detected
  • Tracks progress over time with repeated assessments
  • Provides data-backed insights for therapists and educators

User Interface Design

Built on strong Human-Computer Interaction (HCI) principles

👶 Child-Friendly Design

  • Bright, attractive colors
  • Large clickable icons
  • Minimal text usage
  • Easy, intuitive navigation
  • Fully Sinhala-based interface
  • No reading requirement for children

♿ Accessibility Features

  • Visual-first interaction throughout
  • Sign videos for every option
  • Voice output to support parent understanding
  • No dependence on spoken or written language

👨‍👩 Parent-Friendly Design

  • Clear Sinhala text display of child's message
  • Simple, predefined response options
  • Sign visual paired with every message
  • Easy understanding of child's exact needs
